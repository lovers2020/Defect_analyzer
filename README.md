# DefectAnalyzer

Excel / CSV 공정 부적합 데이터를 검색하고 불량 수량과 조치 완료율을 분석하는 대시보드입니다.

## 실행

Node.js 환경에서 다음 명령을 실행합니다.

```sh
npm install
npm run dev
```

## 검증 및 배포

```sh
npm run lint
npm run build
```

Vercel에서 `npm run build`로 빌드하고 `dist`를 배포합니다.

## 사용

- 파일 업로드 또는 샘플 파일로 시작합니다. 첫 번째 시트의 7번째 행을 헤더로 읽습니다.
- 제품군·모델명·부적합 증상·발생원인으로 검색합니다.
- 원본 데이터 탭에서 검색하고 열 너비를 조정할 수 있습니다.
- 결과 내보내기는 현재 검색된 데이터를 Excel 파일로 저장합니다.
- LOT별 불량률 탭에서 제품군·제품명·LOT·LOT 수량·불량 수량·불량률을 조회하고 열 제목으로 정렬할 수 있습니다. 이 탭에서 결과 내보내기를 누르면 LOT 집계가 저장됩니다.
- 제품군별 상세 탭에서 제품군을 선택해 증상별 불량 수량과 모델·LOT·증상 원문·발생원인·조치 완료 수량을 확인합니다. 기존 검색 조건이 적용되며 LOT 수량이 불명확한 기록도 상세보기에는 포함됩니다. 이 탭에서 결과 내보내기를 누르면 선택 제품군의 증상별 집계와 상세 내역이 두 시트로 저장됩니다.
- LOT별 불량률은 같은 LOT의 불량 수량 합계 ÷ LOT 수량 × 100으로 계산합니다. 제품군·모델명이 달라도 LOT 표기가 같으면 묶습니다. 검사수량은 사용하지 않으며 `1K`는 1,000대, `2418`은 2,418대로 해석합니다. LOT 수량을 해석할 수 없는 기록은 LOT 집계에서만 제외합니다. 기존 검색 필터가 적용되며, 재불량과 중복 기록을 자동 제거하지 않습니다.
- 조치 완료율은 첫 번째 조치 완료일이 2차 재불량 발생일보다 늦은 행의 불량 수량을 기준으로 계산합니다(엑셀 완료수량 수식과 동일). 재불량 발생일 열이 없는 파일은 완료일 존재 여부를 사용하며, 기존 조치수량 열도 지원합니다.
